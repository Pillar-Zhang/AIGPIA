电网数字化员工智能巡检双APP功能需求
一、整体架构设计
系统采用“AR眼镜端轻量APP + 手机端边缘计算主APP”分离架构设计，依托WiFi 6/蓝牙5.4实现双端低延迟双向通信，构建“眼镜端采集显示、手机端计算处理、双端协同作业”的工业级智能巡检体系。手机端APP替代传统边缘计算网关，承担核心算力与业务枢纽功能；眼镜端APP聚焦现场作业，实现轻量化采集、交互与AR信息展示，双端分工明确、联动高效，完全匹配电网巡检工业场景需求。
双APP通信标准：通信延迟≤20ms，数据传输丢包率≤0.1%，支持断连自动重连，采用加密传输协议保障数据安全。
二、AR眼镜端轻量APP（简称：眼镜端APP）
（一）运行环境要求
1. 适配系统：AR眼镜专用轻量化Android（Android 10+）/Linux系统
2. 硬件适配：支持眼镜端BLE 5.4、WiFi 6、摄像头、麦克风、骨传导扬声器、手势传感器、六轴传感器
3. 性能要求：占用内存≤200MB，启动时间≤3s，7×24小时连续运行无崩溃，功耗≤1.5W（保障眼镜续航≥6小时）
（二）核心功能模块
1. 设备联动与初始化模块
- 自动扫描并配对手机端主APP，支持二维码一键绑定，完成双端通信链路建立；
- 实时检测眼镜端硬件状态（摄像头、麦克风、传感器、电量、信号），异常状态（如电量＜20%、摄像头故障）本地语音+视觉告警，并同步至手机端APP；
- 接收手机端APP的初始化指令，完成作业场景、设备样本库、巡检任务的本地加载。

2. AR信息显示模块（核心功能）
- 支持虚拟信息与实景融合显示，可叠加展示：UWB+蓝牙融合定位导航箭头、设备名称/型号/参数、巡检作业步骤、危险区域警示框、异常告警信息、远程专家标注指引；
- 显示界面支持自适应调节，可根据环境光照自动调整亮度，支持单/双视野切换，AR视场角≥50°，显示分辨率匹配眼镜硬件标准；
- 支持作业信息分层展示，可通过手势/语音控制隐藏/调出指定信息层（如仅显示导航或仅显示设备参数）。

3. 现场数据采集模块
- 图像/视频采集：联动眼镜端摄像头，实现设备、铭牌、表计图像的自动/手动采集，支持4K高清视频录制（30fps），采集数据实时透传至手机端APP；
- 状态数据采集：实时采集眼镜端传感器数据（姿态、位置变化），同步至手机端APP辅助定位与作业行为分析。

4. 语音/按键交互模块
- 语音交互：支持中文语音指令识别（准确率≥98%），核心指令包括“下一步操作”“设备识别”“发起专家求助”“隐藏信息”“确认完成”，支持语音唤醒，无唤醒词时低功耗监听；
- 交互反馈：语音/按键操作后，通过本地短音/视觉闪烁实现即时反馈，确保操作有效。

5. 双端通信与数据透传模块
- 建立与手机端APP的长连接通信，支持WiFi 6（主通信）/蓝牙5.4（备用通信）无缝切换，WiFi 6断连时自动切换至蓝牙，保障数据传输不中断；
- 实时透传采集的图像、视频、语音指令、操作反馈数据至手机端APP，接收手机端APP下发的定位、导航、作业指引、告警等数据；
- 支持小体积数据本地缓存（≤100MB），断连时缓存核心操作指令，重连后自动补发至手机端APP。

6. 本地告警模块
- 接收手机端APP的告警指令，实现语音+视觉双重告警：危险区域接近时发出红色视觉框+语音提示“靠近高压设备，请注意安全”，操作错误时发出红色闪烁+语音提示“操作错误，请确认”；
- 支持本地低电量、硬件故障告警，语音提示简洁明了，适配现场作业环境。

（三）核心非功能要求
1. 稳定性：7×24小时连续运行无闪退、无卡死，双端断连重连成功率100%；
2. 低功耗：所有功能运行时总功耗≤1.5W，无操作时自动进入低功耗模式（功耗≤0.5W）；
3. 易用性：交互方式仅保留语音+手势，无手动触屏操作，适配巡检人员双手作业场景；
4. 兼容性：适配项目定制化AR眼镜硬件，支持硬件参数小幅调整后的无缝适配。
三、手机端边缘计算主APP（简称：手机端APP）
（一）运行环境要求
1. 适配系统：旗舰手机Android 12+/iOS 16+（以Android为主，支持国产化系统适配）
2. 硬件适配：支持5G/4G、WiFi 6、蓝牙5.4、UWB外接模块、NFC、大存储（≥256G）、NPU（算力≥30TOPS）
3. 性能要求：支持7×24小时连续运行，本地AI推理延迟≤30ms，数据处理并发量≥10路，占用内存≤1GB

（二）核心功能模块
1. 设备管理与多端联动模块
- 主设备管理：对接手机端外接硬件（工业级UWB模块、BLE主站模块），实现硬件的一键初始化、状态监测、固件升级，支持硬件故障自动识别与告警；
- 从设备联动：管理AR眼镜端APP，实现双端配对、通信链路监控、指令下发、数据同步，支持同时连接≥8台AR眼镜端APP，满足多人协同巡检需求；
- 设备状态可视化：在手机端界面实时展示所有关联设备（UWB基站、AR眼镜、外接模块）的运行状态、电量、信号强度，异常状态标红并提示处理方案。

2. UWB+蓝牙融合定位解算模块（核心算力功能）
- 接收外接工业级UWB模块的测距数据，运行TOF定位算法+多路径信号抑制算法+NLOS误差修正模型，完成室内外一体化精准定位（精度≤0.5m，定位更新频率≥10Hz）；
- 联动BLE主站模块，实现蓝牙补盲定位，UWB信号中断时自动切换为蓝牙定位（精度≤1m），保障定位连续性；
- 构建变电站电子地图，实时解算巡检人员位置，生成最优巡检路径，将定位坐标、导航箭头数据实时下发至眼镜端APP。

3. 边缘计算与AI推理模块（核心算力功能）
- 本地部署轻量化AI算法模型，包括：YOLOv8设备/间隔识别模型、EfficientNet-B4 OCR铭牌提取模型、表计读数识别模型（数字+指针）；
- 接收眼镜端APP采集的图像数据，本地完成AI推理，实现设备识别（准确率≥96%、速度≥30fps）、铭牌信息提取（准确率≥98%）、表计读数识别（准确率≥95%），推理结果实时下发至眼镜端APP；
- 支持算法模型本地迭代升级，可通过电网内网接收最新模型包，无需卸载APP即可完成更新。

4. 电网专网通信与业务系统对接模块
- 电网5G专网适配：内置电网专用5G APN配置模板，支持一键接入5G/4G电网专网，分配差异化网络切片（远程协同音视频：低延迟切片≤20ms；图像/定位数据上传：高带宽切片≥100Mbps；操作指令：高可靠切片≥99.99%）；
- 核心系统对接：实现与电网PMS3.0、OMS系统的标准化接口对接，支持IEC 61850、Modbus、MQTT等电力通信协议，完成巡检任务下发、设备台账调取、巡检数据上传、操作票校验、报告归档等全流程业务交互；
- 数据交互标准化：对上传/下发数据进行格式统一处理，确保与电网核心系统数据交互的兼容性与一致性，接口调用成功率≥99.5%。

5. 安全加密与权限管控模块
- 数据加密：集成国密算法套件（SM2身份认证、SM3数据完整性校验、SM4数据加密），建立IPSec VPN加密隧道，实现巡检数据、定位数据、操作记录在传输/存储过程中的全链路加密；
- 权限管控：实现基于角色的三级权限管控体系，包括**数字化员工**（仅可读取对应设备信息、上传巡检数据、执行作业任务）、**操作负责人**（可下发作业指令、审核巡检报告、解锁操作流程）、**系统管理员**（可配置权限、升级算法、管理设备），不同角色登录后仅展示对应功能模块；
- 身份认证：支持人脸识别、账号密码双重认证，人脸识别准确率≥99.8%，登录信息本地加密存储，无明文传输。

6. 巡检业务全流程管理模块
- 任务接收与解析：从PMS3.0系统接收巡检任务，自动解析任务清单、作业标准、安全注意事项，匹配对应的设备样本库与定位路径；
- 作业过程管控：实时监控巡检作业进度，记录已完成/未完成巡检点，支持作业过程暂停、继续、终止，偏离规划路径时自动下发告警指令至眼镜端APP；
- 操作监护：对接OMS系统实现倒闸操作票校验，完成操作对象精准确认、操作步骤实时校验、误操作/漏操作告警，确保倒闸操作规范性达标率≥99%；
- 异常处置与远程协同：支持巡检人员通过眼镜端/手机端发起远程专家求助，建立音视频连接（响应时间≤3s），实现AR视野共享、远程标注指导、作业文档推送，专家标注信息实时下发至眼镜端APP；
- 报告自动生成与归档：巡检/操作任务完成后，自动汇总巡检数据、定位轨迹、操作记录、异常信息，生成标准化电子报告，附带图像/视频佐证材料，一键上传至PMS3.0/OMS系统完成归档。

7. 本地缓存与断网续传模块
- 断网缓存：电网专网中断时，自动加密缓存巡检数据、定位轨迹、操作记录、图像/视频数据（缓存容量≥50GB），支持断点续存，不覆盖历史数据；
- 自动续传：网络恢复后，自动检测缓存数据，按“重要性优先”原则（告警信息＞操作记录＞图像/视频）完成数据补传，补传完成后可手动/自动删除本地缓存；
- 缓存管理：支持手机端查看缓存数据列表，手动筛选删除、强制上传，缓存数据保存时间可配置（1-7天）。

 8. 数据管理与可视化模块
- 本地数据管理：支持巡检数据、定位轨迹、操作记录、报告的本地查询、筛选、导出，按时间/变电站/作业类型分类存储，查询响应时间≤1s；
- 数据可视化：以图表、地图形式展示巡检作业进度、设备异常统计、定位轨迹，支持历史轨迹回放，直观呈现作业过程；
- 数据统计分析：自动统计巡检效率、漏检率、操作合格率等核心指标，生成日报/周报/月报，支持导出为Excel格式，为运维管理提供数据支撑。

9. 系统设置与运维模块
- 基础设置：支持网络配置、音视频参数、告警方式、缓存策略、权限申请等功能的可视化配置；
- 固件/算法升级：支持通过电网内网实现APP自身、外接硬件固件、AI算法模型的远程自动/手动升级，升级过程不影响核心作业功能；
- 日志管理：自动记录APP运行日志、设备交互日志、数据传输日志，日志保存时间≥3个月，支持日志导出与异常日志筛选，便于问题排查。

（三）核心非功能要求
1. 算力性能：本地AI推理延迟≤30ms，定位解算延迟≤10ms，满足实时作业需求；
2. 稳定性：7×24小时连续运行无崩溃，网络切换/设备断连时核心功能不中断；
3. 安全合规：通过电力行业等保三级认证，符合《电力监控系统安全防护规定》《电力数据安全管理办法》；
4. 兼容性：适配主流旗舰手机硬件（骁龙8 Gen4/天玑9400/苹果A18 Pro），支持外接工业级UWB/BLE模块的标准化对接；
5. 易用性：界面布局简洁，核心功能一键触达，支持大屏适配与横屏操作，适配现场单手操作需求。

四、双APP协同作业核心流程
1. 作业初始化流程
1. 手机端APP登录并接入电网5G专网，对接PMS3.0/OMS系统，接收巡检/操作任务；
2. 手机端APP连接外接UWB/BLE模块，完成定位初始化，构建变电站电子地图与巡检路径；
3. AR眼镜端APP开机，自动配对手机端APP，建立通信链路；
4. 手机端APP将巡检任务、设备样本库、初始定位数据下发至眼镜端APP，完成双端作业初始化。

2. 常规巡检作业流程
1. 眼镜端APP实时接收手机端APP的定位与导航数据，AR视野展示导航箭头，引导巡检人员前往巡检点；
2. 到达巡检点后，眼镜端APP自动采集设备图像，透传至手机端APP；
3. 手机端APP本地完成AI推理（设备识别、铭牌提取、表计读数），将设备信息下发至眼镜端APP，AR视野叠加展示；
4. 巡检人员通过语音/手势完成操作确认，眼镜端APP将操作反馈透传至手机端APP；
5. 手机端APP记录操作信息，同步至电网核心系统，完成单个巡检点作业；
6. 重复1-5步，直至完成所有巡检点，手机端APP自动生成巡检报告并归档。

 3. 异常处置与远程协同流程
1. 眼镜端APP采集到设备异常图像，透传至手机端APP，手机端APP本地识别并触发异常告警，下发至眼镜端APP；
2. 巡检人员通过语音/手势发起远程专家求助，眼镜端APP将求助指令透传至手机端APP；
3. 手机端APP快速建立与专家终端的音视频连接，同步AR视野、设备异常图像、定位数据至专家终端；
4. 专家在终端进行远程标注，标注信息下发至手机端APP，再由手机端APP同步至眼镜端APP，AR视野叠加展示；
5. 巡检人员根据专家指导完成异常处置，操作反馈经双端同步后，由手机端APP记录并上传至电网核心系统。

 4. 断网应急作业流程
1. 电网专网中断时，手机端APP触发断网提示，自动进入本地缓存模式；
2. 眼镜端APP继续采集作业数据，透传至手机端APP完成本地加密缓存，定位与AI推理继续本地运行，不影响现场作业；
3. 巡检人员正常完成现场作业，所有操作记录、图像/视频、定位轨迹均缓存至手机端；
4. 网络恢复后，手机端APP自动触发断网续传，将缓存数据按优先级上传至电网核心系统，完成作业闭环。
